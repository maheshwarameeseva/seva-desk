## Deploying to GitHub Pages

The `Deploy to GitHub Pages` workflow builds and publishes the production app when changes are pushed to `main`. You can also start it manually from the **Actions** tab with **Run workflow**.

Before the first deployment, open **Settings → Pages** for the repository and set **Build and deployment → Source** to **GitHub Actions**. The workflow automatically sets the Angular base path for either a project site (`/<repository>/`) or a user/organization site (`/`), and publishes a `404.html` fallback for Angular client-side routes.

If the repository's default branch is not `main`, update the branch under `on.push.branches` in `.github/workflows/deploy.yml`.
